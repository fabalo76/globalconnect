# Continental Payment Systems — Google Workspace assets

## Google Workspace logo

Upload `continental-payment-systems-workspace-logo-320x132.png` in the Google Admin console under **Account → Account settings → Personalization**.

- Canvas: 320 × 132 px
- Format: optimized transparent PNG
- Designed for the light Google Workspace interface
- The 1280 × 528 px file is the higher-resolution master and should not be uploaded directly if the Admin console enforces the 30 KB limit.

## Gmail signature

1. Host `continental-payment-systems-email-logo-400x100.png` on a public HTTPS URL or in an appropriately shared Google Drive location.
2. Open `email-signature-template.html` in a text editor.
3. Replace `{{LOGO_URL}}`, `{{FULL_NAME}}`, `{{JOB_TITLE}}`, `{{PHONE_LINK}}`, `{{PHONE_DISPLAY}}`, and `{{EMAIL}}`.
4. Open the edited HTML in a browser, select the rendered signature, and copy it.
5. In Gmail, go to **Settings → See all settings → General → Signature**, create a signature, paste it, and save changes.

`email-signature-preview.html` and `continental-payment-systems-email-signature-preview.png` show the intended layout with sample information.
